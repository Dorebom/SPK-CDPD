# Standalone ChatGPT Web provider

添付ソース由来の非公式Web UI操作adapter。Python importは`chatgpt_web_api`、generic facade名は`chatgpt-web.facade/v2`。ブラウザ操作にはoptional Playwrightが必要。公式OpenAI API/SDKではなく、サイト利用条件の確認が別途必要。旧tools import互換は提供しない。
