# CDPD core

任意の許可対象を診断する独立SDK/CLI。Python importは`cdpd`。`DiagnosticService.capabilities()`で現状を取得する。coreだけの導入は他3packageを必要としない。実CDP採取にはoptional dependency `websocket-client`が必要。
